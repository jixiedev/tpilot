An AI agent platform for data teams

Ask a question in a terminal or a browser. TahoePilot routes it to a specialist that reasons with an LLM and calls read-only tools against your warehouse, catalog, cluster, and team knowledge — and waits for you before anything consequential runs.

What it does

Routes to a specialist

The default intent agent classifies a question and hands it to one specialist, or to the plan agent when the work needs several.

Answers with approval

Databot finds candidate tables, drafts SQL, and runs it on Trino only after you approve both the tables and the query.

Keeps long conversations

Sessions are checkpointed, so a named session resumes after a restart. Long histories compress without dropping anything.

Configured, not coded

Each agent's prompt, budgets, tool set and connections are set in configuration, so behaviour changes without a deployment.
